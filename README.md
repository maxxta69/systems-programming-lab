# Systems Programming Lab

A collection of projects and experiments focused on systems programming, Linux, networking, backend development, and scripting.

This repository documents my progress as I explore how software interacts with operating systems, files, networks, and low-level system resources.

## Repository Structure

### C

#### `file-reading`

Experiments with file input, file streams, buffers, and the C standard library.

#### `tcp-server`

A networking project exploring TCP sockets and client-server communication in C.

### C++

#### `packet-sniffer`

A networking project focused on capturing and inspecting network packets.

#### `port-decoder`

Experiments with interpreting port information and network data.

### JavaScript

#### `sys-recon`

JavaScript utilities for system reconnaissance, information processing, <!--backend tasks,--> and scripting.

Current files include:

- `sys-recon.js` — Main system reconnaissance script
- `conversions.js` — Contains necessary conversions of parameters obtained from the system(imported and used by `sys-recon.js`)
